## Repository Structure

The directory tree is organized as follows to separate coursework, core simulation assets, and manuscript drafts:

* `📁 coursework/`: Lecture notes, assignments, and mini-projects from completed M.Sc. classes.
* `📁 research/`: The core technical engine of this thesis.
    * `/datasets`: Network traffic, channel models, or simulation logs (large files are externalized).
    * `/models`: Soft computing, fuzzy logic systems, or neural network architectures.
    * `/simulations`: Network simulation scripts (e.g., NS-3, MATLAB, Python/PyTorch).
    * `/analysis_scripts`: Scripts used for data post-processing and generating thesis/paper plots.
* `📁 writing/`: LaTeX source files for the qualifying exam, manuscripts, and the final dissertation.
    * `/templates`: IEEE Transactions / University thesis formatting styles.
    * `/proposals`: Qualification exam drafts.
    * `/papers`: Manuscripts for targeted conferences/journals (e.g., IEEE Globecom, ICC, Open Journal).
* `📁 presentations/`: Slide decks used for seminars, qualification, and the final defense.
